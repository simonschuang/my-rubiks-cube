## Features

### 3D Interactive Rubik's Cube
- Rotate the cube by dragging the background
- Rotate individual layers by dragging cube faces
- Smooth animations and realistic rendering

### Camera Scanner (OpenCV.js)
- Scan real Rubik's cube faces using your device camera
- Face-by-face guided scanning (U, R, F, D, L, B order)
- OpenCV.js powered face detection and perspective correction
- Auto-orientation to canonical orientation
- Manual color correction for each captured face
- Export scanned cube as:
  - Human-readable thumbnail grid
  - Kociemba-compatible cube string
- Apply scanned colors to 3D cube model

## Testing on GitHub Pages

1. **Visit the live site**: https://simonschuang.github.io/my-rubiks-cube/
2. **Test basic cube interaction**:
   - Click and drag the background to rotate the camera view
   - Click and drag a cube face to rotate that layer
3. **Test the scanner**:
   - Click the "Scan Cube" button
   - Grant camera permissions when prompted
   - Follow the on-screen instructions to scan each face in order:
     - **U (Up/White)** - Top face
     - **R (Right/Red)** - Right face
     - **F (Front/Green)** - Front face
     - **D (Down/Yellow)** - Bottom face
     - **L (Left/Orange)** - Left face
     - **B (Back/Blue)** - Back face
   - After each capture, use the color correction interface to fix any misidentified stickers
   - After all 6 faces are scanned, view the thumbnail and Kociemba string
   - Click "Apply to 3D Cube" to see your scanned colors on the 3D model
